# Hi, I'm Ankit Gupta <img src="https://media.giphy.com/media/hvRJCLFzcasrR4ia7z/giphy.gif" width="28">

**Backend & AI Engineer** based in Amsterdam. I build the APIs, pipelines and deployments that put AI models into production, mostly in healthcare, where the data is sensitive and "it works on my laptop" isn't good enough.

## What I work on

- **LLM pipelines**: extraction and evaluation pipelines on locally hosted models (Llama, Meditron via Ollama), so sensitive data never leaves the building
- **Backend engineering**: Python, FastAPI, Django, Flask, REST APIs, PostgreSQL
- **ML deployment**: Docker, CI/CD, Ansible, AWS, cloud and on-premise rollouts
